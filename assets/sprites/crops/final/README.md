# Valley Tapping crop production sprites

Extracted from the approved high-detail pixel-art source sheet. PNGs retain RGBA alpha and are not re-drawn.

- `approved-master-sheet.png`: original source sheet.
- `<crop>/01-seed.png` through `09-ripe_3.png`: individual stage cells for carrot, wheat, potato, tomato, strawberry and blueberry.
- `*-harvest-items.png`: crop-specific harvest artwork strip. Inspect/crop item variants for inventory use.

All sprites are PNG with alpha; no scaling or palette simplification was applied. Stage cell crops are individually separated but still need visual QA against the source before shipping as in-game objects, since the source sheet's cell boundaries are hand-estimated.
