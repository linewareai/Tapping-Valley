# ValleyTapping Mobile (Godot)

Este directorio está reservado para la futura versión nativa de ValleyTapping para Android y iOS, con pixel art cenital detallado.

## Estado
Planificación técnica. El cliente nativo todavía no está implementado aquí. La versión web existente sigue siendo el prototipo.

## Requisitos del primer prototipo
- Godot 4.x estable, proyecto 2D.
- Diseño adaptable a móvil y controles táctiles desde el comienzo.
- Cámara top-down y tiles con arte original.
- Escenas separadas para granja, inventario, mascotas y menú.
- Guardado local versionado antes de conectar el backend.
- Sin secretos de backend dentro del cliente.

Ver [la hoja de ruta móvil y online](../docs/ROADMAP-MOBILE-ONLINE.md) para las fases, la arquitectura de amigos/visitas y las reglas del mercado.
